## 💻 How to Run Locally

This website has **zero external build steps or npm dependencies** — it runs out of the box in any web browser!

### Option 1: Direct File Open
Simply double-click `index.html` in your file explorer, or right-click and choose **Open with Google Chrome / Microsoft Edge / Firefox**.

### Option 2: Using Python Local Server
Open your terminal in this project directory and run:
```bash
python -m http.server 8000
```
Then visit `http://localhost:8000` in your web browser.

## 🚀 How to Deploy for Free

### GitHub Pages (Recommended)
1. Initialize a git repository and commit all files:
   ```bash
   git init
   git add .
   git commit -m "Initial portfolio commit"
   ```
2. Create a new repository on GitHub (e.g. `portfolio` or `<your-username>.github.io`).
3. Push your repository:
   ```bash
   git remote add origin https://github.com/<your-username>/<your-repo-name>.git
   git branch -M main
   git push -u origin main
   ```
4. Go to **Settings > Pages**, choose `main` branch, and click **Save**. Your site will be live in seconds!

### Vercel or Netlify
- Drag and drop this folder directly into the Netlify or Vercel dashboard for instant deployment with free SSL.
